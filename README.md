# Warranty Manager

A 100% free, privacy-first, and offline-first Flutter application to organize and track all your device warranties and receipts in one place.

## Features

- **Offline-First:** All your data stays strictly on your local device. No account or cloud login required.
- **Privacy-Focused:** No tracking, no ads, no external servers.
- **Warranty Tracking:** Easily manage purchase dates, warranty expiration, and receipts.
- **Cross-Platform:** Built with Flutter & Dart for Android and Web (PWA).

## How to Use / Install

### Android
Download the latest `.apk` file from the [Releases](../../releases) section and install it on your Android device.

## 🔒 Privacy Policy

**Warranty Manager** does not collect, store, or transmit any personal data. All information entered into the application remains stored locally on your device.
